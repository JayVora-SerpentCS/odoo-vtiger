VTiger HelpDesk Connector
=========================

This module synchronizes VTiger HelpDesk tickets into Odoo Helpdesk.

Features
--------

* Import VTiger HelpDesk ticket records into Odoo ``helpdesk.ticket``.
* Store VTiger ticket number, status, category, severity, and solution.
* Link tickets to synced Odoo partners when VTiger contact or account references
  are available.
* Add a manual sync button on the VTiger company configuration page.
