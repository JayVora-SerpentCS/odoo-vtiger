VTiger Documents Connector
==========================

This module synchronizes VTiger document files into Odoo DMS.

Features
--------

* Keep VTiger document IDs for reliable updates on later synchronizations.
* Add a manual sync button on the VTiger company configuration page.

Dependencies
============

This module requires the following OCA module:

* Technical Name: dms
* Repository: OCA/dms/tree/18.0/dms
* Branch: 18.0

Please install the required OCA dependency before installing this module.
