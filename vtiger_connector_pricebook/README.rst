VTiger Price Book Connector
===========================

This module synchronizes VTiger Price Books into Odoo pricelists.

Features
--------

* Import VTiger Price Book records into Odoo pricelists.
* Store VTiger ID, active flag, and description on the Odoo pricelist.
* Add VTiger filters and fields on pricelist views.
* Add a manual sync button on the VTiger company configuration page.
